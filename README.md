#  Flight Booking System with RAG (In Progress)

# Overview
A command-line Flight Booking System built using Python and SQLite. It allows users to register, log in, view available flights, book tickets, view bookings, and cancel bookings. This project is being extended with a Retrieval-Augmented Generation (RAG) chatbot for natural language flight queries.

# Features
- User Registration
- User Login
- View Available Flights
- Book Flight Tickets
- View My Bookings
- Cancel Bookings
- Seat Availability Management
- SQLite Database Integration

# Technologies Used
- Python
- SQLite
- Git
- GitHub
